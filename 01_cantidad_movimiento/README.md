# Operaciones de transferencia de cantidad de movimiento
Resumen teóricos y ejercicios de aplicación resueltos con python.

## Conceptualización :
- Capítulo 1 : análisis estático en fluidos.
- Capítulo 2 : análisis de flujo en fluidos incompresibles (líquidos), balances energéticos.
- Capítulo 3 : análisis de flujo en fluidos compresibles (vapores-gases), balances energéticos.
- Capítulo 13 : Flujo en medio poroso.

## Funciones comunes :
Se registran las funciones y expresiones mas usadas para el desarrollo de análisis en las operaciones de transferencia de cantidad de movimiento.
